# Dự án Website Văn Phòng Phẩm

Website quản lý cửa hàng văn phòng phẩm **hiện đại** và _tiện lợi_.

## Cấu trúc thư mục

| Thư mục / File | Nội dung                           |
| :------------- | :--------------------------------- |
| `docs/`        | Chứa các tài liệu nhập hàng        |
| `media/`       | Chứa hình ảnh, logo hình ảnh dự án |
| `data/`        | Chứa dữ liệu Excel đơn bán         |
| `logs/`        | Chứa các file log hệ thống         |
| `backup/`      | Thư mục sao lưu dữ liệu            |

## Kiểm tra cấu trúc dự án

```powershell
Get-ChildItem -Recurse -Force
Danh sách công việc
[x] Sắp xếp lại danh sách file và thư mục

[ ] Hoàn thiện báo cáo doanh thu Excel

Lưu ý quan trọng: Tuyệt đối không upload file .env lên các repository công khai!
```
